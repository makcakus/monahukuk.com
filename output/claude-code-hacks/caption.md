Most Claude Code frustration is a setup problem, not a model problem.

The difference between a tool that guesses and one that works like a colleague is what you put around it. A CLAUDE.md that carries your commands and conventions into every session. Plan mode before any change worth reviewing. A clean context when the task shifts. Hooks that run your formatter and tests so nothing depends on memory. Skills that turn the work you repeat into something written once.

None of this takes more than an afternoon, and every hour after it is quieter.
